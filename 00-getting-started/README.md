# Stufe 0 – Getting Started 🌱

**Ziel:** Du bist mit deiner Entwicklungsumgebung vertraut und hast dein erstes Programm geschrieben – inklusive Variablen und Benutzereingaben.

Wenn du Python und VS Code noch **nicht** installiert hast, hole das jetzt über [`START_HERE.md`](../START_HERE.md) nach (Schritte 1–4).

## Aufgaben

| # | Aufgabe | Schwierigkeit |
|---|---|---|
| 0.1 | [`tasks/01-hello-world.md`](tasks/01-hello-world.md) – dein erstes Programm | Anfänger |
| 0.2 | [`tasks/02-variablen-und-eingabe.md`](tasks/02-variablen-und-eingabe.md) – Variablen, Strings, Zahlen, Eingaben | Anfänger |

## Wie du arbeitest

1. Lies die Aufgabe in `tasks/` **vollständig** bis zum Abschnitt „Deine Mission".
2. **Versuche es selbst** – nutze die Hinweise erst, wenn du nicht weiterkommst.
3. Vergleiche erst danach mit `solutions/` und lies den Code-Walkthrough.
4. Prüfe die „Reflexionsfragen" – wenn du sie beantworten kannst, hast du verstanden, nicht nur kopiert.

## Ausführen

```bash
# im Projektordner (Windows: python statt python3)
python3 00-getting-started/solutions/hello_world.py
python3 00-getting-started/solutions/personal_greeting.py
```
