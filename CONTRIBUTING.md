# 🤝 Mitmachen

Danke für dein Interesse! So kannst du helfen:

## Fehler melden
- Erstelle ein Issue und beschreibe: Was hast du gemacht? Was hast du erwartet? Was ist passiert (ggf. mit Fehlermeldung)?
- Nenne deine Python-Version und dein Betriebssystem.

## Inhalte verbessern
1. Forke das Repository und lege einen Branch an (`git checkout -b mein-verbesserungsvorschlag`).
2. Verringerungen und neue Aufgaben folgen dem 16-Sektionen-Template (siehe eine beliebige Datei in `tasks/`).
3. Alle Lösungen müssen ohne API-Key im Offline-Modus lauffähig sein.
4. Lasse die Tests laufen: `pip install -r requirements.txt && pytest`
5. Erstelle einen Pull Request mit einer kurzen Erklärung.

## Regeln
- Lernende-Dokumentation auf Deutsch; Code, Bezeichner und Paketnamen auf Englisch.
- **Niemals** echte API-Keys committen.
- Keine veralteten/deprecated APIs – prüfe die aktuelle Dokumentation (python.langchain.com, docs.langchain.com, docs.mistral.ai).
